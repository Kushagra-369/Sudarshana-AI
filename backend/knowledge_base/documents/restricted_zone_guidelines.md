# SUDARSHANA-AI Demonstration
# Restricted Zone Monitoring Guidelines

## Purpose

These fictional guidelines describe how an AI-assisted
monitoring system can support awareness around a designated
restricted monitoring zone.

## Zone Entry

When a person or vehicle is detected inside a monitored
restricted zone, the system should generate an event for
operator awareness.

## Anomalous Activity

If movement inside the zone differs significantly from the
configured normal movement pattern, the event may receive
an elevated anomaly score.

## Operator Review

A restricted-zone event should be reviewed together with
the detection confidence, tracking information, anomaly
level, and risk score.

## False Positives

Automated detection can produce false positives because of
occlusion, lighting conditions, camera angle, or model
uncertainty.

Human verification is therefore required before making
important decisions.

## Response

The system should provide relevant information to the
operator rather than autonomously determine intent or
initiate an operational response.
